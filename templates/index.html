🔎 Databricks App Setup Guide
Authorize callback URL — paste this into Databricks as the app's Redirect URL
https://formabricks-stg.cctech.co.in/databricks/callback
  1. Go to your Databricks account console.
  2. Navigate to Settings → App connection.
  3. Click Add, give the app a name, and set the Redirect URLs to the authorize callback URL above.
  4. Under Access scopes, select all API and offline access.
  5. Keep Generate a client secret turned on.
  6. Click Add, then paste the generated Client ID and Client Secret into this form along with your workspace URL.
Example: *.cloud.databricks.com (other valid Databricks hosts are also allowed)
